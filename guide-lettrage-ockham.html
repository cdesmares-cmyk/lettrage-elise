Module Lettrage
Guide d'utilisation

Réconciliation des virements bancaires avec vos factures clients — pas à pas.

1 Présentation générale

Le module de lettrage est le cœur de la réconciliation comptable. Il permet de faire correspondre chaque virement reçu sur votre compte bancaire avec une ou plusieurs factures clients.

💡
Principe fondamental
Chaque crédit sur votre relevé bancaire doit être "lettré" — c'est-à-dire relié à une ou plusieurs factures. Une ligne non lettrée reste en suspens jusqu'à l'export comptable.

Les onglets permettent de naviguer entre les différents états des lignes bancaires :

Virements reçus, pas encore affectés à une facture.
Partiels

2 Codes couleur et statuts

Chaque ligne bancaire affiche un badge coloré indiquant son état de traitement.

3 Lettrage direct

Cas le plus courant : un virement client correspond directement à une ou plusieurs factures identifiables.

📅
Règle de date — La date du lettrage est automatiquement celle de la ligne bancaire (date du virement). Vous n'avez rien à saisir.
📋 Procédure pas à pas
1
Sélectionner une ligne dans l'onglet "À lettrer"
Cliquez sur la ligne bancaire à traiter. Le panneau de lettrage s'ouvre à droite avec le montant disponible à affecter.
2
Saisir le ou les numéros de factures
Tapez directement un numéro de facture — le système cherche automatiquement et affiche le solde restant dû. Vous pouvez ajouter plusieurs lignes pour ventiler le virement.
3
Vérifier les montants
La barre de progression indique le % attribué. Un badge vert "100 %" confirme l'équilibre parfait. Vous pouvez aussi laisser un reliquat si le virement ne couvre pas tout.
4
Valider
Cliquez sur "Valider le lettrage". La ligne passe en statut Lettré ou Partiel selon le montant attribué.

4 Détection automatique

Le bouton "Détection auto" analyse le libellé du virement et propose les factures les plus probables. Utile pour les clients réguliers ou quand la référence est lisible dans le libellé.

Factures lettrées sur des virements similaires Historique ⬤◯◯ Indicative
💡
Vous pouvez aussi rechercher manuellement par code client, nom ou numéro de facture dans la barre de recherche de la modale. Les résultats montrent le montant TTC et le restant dû en temps réel.
📋 Procédure
1
Cliquer sur "Détection auto"
Disponible dans le panneau de lettrage, dans les vues 411 Client et 411 Attente.
2
Sélectionner les factures proposées
Cochez une ou plusieurs factures dans la liste. Le total sélectionné s'affiche en bas de la modale.
3
Injecter dans le formulaire
Cliquez sur "↗ Injecter dans le formulaire". Les lignes sont automatiquement pré-remplies avec les montants correspondants.
4
Valider comme pour un lettrage classique
Ajustez les montants si nécessaire, puis validez.

6 411 Attente

Un virement reçu mais dont le client n'est pas encore identifié. On le classe en "Attente" le temps de faire les recherches nécessaires.

⚠️
Différence avec 411 Client — Le 411 Attente est un compte commun à tous les virements non identifiés. Il ne porte pas de code client spécifique. Une fois le client identifié, on dispatche directement sur ses factures.
📋 Procédure complète
1
Affecter en "411 Attente" depuis "À lettrer"
Dans le panneau de lettrage, choisir "411 Attente" dans le sélecteur. La ligne est marquée comme en attente — elle n'est pas encore affectée à un client ni à une facture.
2
La ligne apparaît dans l'onglet "Compte"
Avec un badge orange distinctif. Elle reste visible jusqu'à ce qu'elle soit intégralement dispatchée.
3
Dispatcher une fois le client identifié
Sélectionner la ligne, utiliser "Détection auto" ou saisir les numéros de factures manuellement, puis valider. La date du dispatch = date du jour.
4
La ligne quitte la vue "Compte"
Les vrais lettrages sont créés sur les factures du client. Le virement est désormais réconcilié.
📅
Dates :
• Affectation initiale en "Attente" : date du virement (pour l'export comptable)
• Dispatch sur les factures : date du jour du dispatch

7 LCR et Chèques

Les Lettres de Change Relevé (LCR) et remises de chèques fonctionnent en deux temps : saisie anticipée, puis confirmation à réception bancaire.

💡
Principe — Vous saisissez la remise avec les numéros de factures avant que la banque ne valide. Cela permet de voir le solde prévisionnel des factures. La facture est officiellement payée seulement quand la ligne bancaire arrive et est associée.
Phase 1 — Saisir la remise
1
Onglet "Remises" → "Saisir une remise"
Choisissez le type (Chèque ou LCR), le numéro de bordereau.
2
Pour LCR : saisir le montant total
Le système vérifie que la somme des factures correspond (tolérance ±5 centimes).
3
Ajouter les numéros de factures
Tapez chaque numéro — le montant restant dû est proposé automatiquement.
4
Créer la remise
La remise apparaît en "À encaisser". Les factures affichent un solde prévisionnel.
Phase 2 — Encaisser
1
La ligne bancaire apparaît dans "À lettrer"
La banque a crédité le montant de la remise.
2
Sélectionner la ligne → choisir la remise
Dans le panneau, choisir "LCR" ou "Chèque" et sélectionner la remise correspondante.
3
Valider l'encaissement
Les factures sont officiellement payées à la date de la ligne bancaire. La remise passe en "Encaissée".
⚠️
Une remise encaissée ne peut plus être modifiée. En cas d'erreur après encaissement, contactez votre administrateur pour une correction via le module dédié.

8 Export comptable

L'export génère un fichier comptable couvrant toutes les lignes 100 % lettrées sur la période sélectionnée et les verrouille définitivement.

🔒
Action irréversible — Une fois l'export lancé, toutes les lignes incluses sont verrouillées. Elles ne peuvent plus être annulées simplement. Toute correction nécessite le module de correction.
📋 Procédure d'export
1
Aller dans l'onglet "Export"
Sélectionner la plage de dates (début / fin de période comptable).
2
Lancer l'aperçu
Le système affiche un résumé : nombre de lignes, montant total, compensations, corrections incluses. Vérifiez avant de continuer.
3
Confirmer et exporter
Téléchargez le fichier Excel. Les lignes sont verrouillées simultanément — tout écart doit être traité en correction.
ℹ️
Ce qui est inclus dans l'export :
• Toutes les lignes bancaires 100 % lettrées sur la période
• Les compensations avoir/facture de la période
• Les corrections de lettrage de la période

Ce qui n'est pas inclus : lignes partielles, 411 non dispatchés, remises non encaissées.

9 Correction d'un lettrage

Après export, si une erreur est détectée, le module de correction permet de délettrer et relettre sans casser la cohérence comptable.

Avant l'export

Annulation simple via la croix (×) sur la ligne dans l'onglet "Lettrés".

Le solde de la facture est restauré immédiatement. Aucune trace comptable.

Après l'export

Module de correction (accessible depuis la barre d'actions).

Une écriture de contre-passation est créée (montant négatif) puis une nouvelle affectation sur la bonne facture. Traçabilité comptable complète.

🔧 Procédure de correction post-export
1
Ouvrir le module de correction
Bouton "Corriger un lettrage" dans la barre d'actions du module Lettrage.
2
Saisir les montants à corriger
Entrez un montant négatif pour la facture à délettrer, un montant positif pour la facture à relettre. Le total doit être égal à zéro.
3
Valider la correction
Les écritures de correction sont créées et seront incluses dans le prochain export comptable. L'historique des corrections est consultable dans l'onglet "Historique" du module.
✅
La correction est toujours possible, même après export. Les nouvelles écritures (correction + reletrage) seront incluses dans le prochain export de la période concernée. Aucune modification de l'export passé.

11 Questions fréquentes

Les situations les plus courantes rencontrées en utilisation quotidienne.

❓ Un virement couvre plusieurs factures de montants différents

Ajoutez autant de lignes que nécessaire dans le panneau de lettrage. Chaque ligne correspond à une facture. Le système vérifie que la somme ne dépasse pas le montant disponible.

❓ Un virement est supérieur à la facture

Deux options : (1) lettrer partiellement la facture et laisser un reliquat en "Partiel", ou (2) ventiler le surplus sur d'autres factures ou en "Autres" avec un commentaire.

❓ Je ne trouve pas la facture dans la recherche

La recherche porte sur les factures avec un solde restant dû non nul. Une facture déjà soldée n'apparaît pas. Si vous cherchez une facture déjà réglée pour correction, utilisez le module de correction.

❓ J'ai fait une erreur de dispatch 411 après l'export

Le dispatch 411 génère des écritures de correction — il reste possible même après export. Ouvrez à nouveau la vue "Compte", sélectionnez la ligne et re-dispatchée sur les bonnes factures. Les anciennes écritures de correction seront contre-passées automatiquement.

❓ Comment retrouver un lettrage passé ?

Dans l'onglet "Lettrés", utilisez le filtre par date ou par client. Vous pouvez aussi rechercher directement depuis la fiche d'un client dans le module Compte Client.

❓ Quelle est la différence entre "Correction" et "Annulation" ?

Annulation (avant export) : suppression pure et simple du lettrage, aucune trace comptable.
Correction (après export) : création d'une contre-passation + nouveau lettrage. Les deux écritures restent visibles dans l'historique pour la traçabilité comptable.
